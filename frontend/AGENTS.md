# 前端 Agent 规则

## 1. 适用范围

本文件适用于 `frontend/**`，并补充仓库根 `AGENTS.md`。不得放宽根规则。

## 2. 模块职责

- 本模块负责：React 页面、路由、交互状态、可访问性、错误边界和经批准的 API 调用。
- 本模块不负责：数据库、磁盘路径、后端业务判断、未经批准的产品行为、解析、AI、RAG 或 Agent 功能。
- 上游依赖：产品需求、视觉方向和冻结的 `/api/v1` 契约。
- 下游使用者：在本机浏览器中使用 StudyPilot 的个人学习者。

TASK-002 只建立应用壳、路由、错误边界和脚手架状态页；页面中的工程说明不是业务功能。

## 3. 必须保持的不变量

- 前端业务代码只调用同源 `/api` 地址，不写死后端主机或端口。
- 开发服务器默认只绑定 `127.0.0.1`。
- 未完成的业务功能不得以假数据、无效按钮或可操作页面伪装为已经可用。
- 用户可见行为变化必须有 React Testing Library 测试；渲染错误必须显示受控提示而不是白屏。
- 不在浏览器持久化未来本地访问令牌或 API Key；不得记录用户正文、笔记或密钥。

## 4. 公共契约

- 架构边界：`docs/architecture/MVP架构与技术选型提案.md`
- 当前页面只承诺明确显示“工程框架已运行，业务功能尚未实现”。
- `/api/v1` 字段、错误和安全协议尚未冻结；未经后续任务授权不得自行定义。

## 5. 准确命令

以下命令已经由 TASK-002 验证，均在 `frontend/` 中运行。

```text
安装：npm ci
启动：npm run dev
格式化：npm run format
格式检查：npm run format:check
静态检查：npm run lint
类型检查：npm run typecheck
模块测试：npm run test -- --run
构建：npm run build
预览正式构建：npm run preview
```

## 6. 文件边界

- 默认允许：具体任务单授权的 `frontend/**` 路径。
- 默认禁止：后端、数据库、治理文档和未获批准的业务契约。
- 生成文件：`node_modules/`、`dist/`、覆盖率、缓存和 `*.tsbuildinfo` 不提交。
- 锁文件要求：依赖变化必须同步提交 `package.json` 和 `package-lock.json`，并重新执行全部前端检查。

## 7. Code Review Rules

### 契约与安全边界

- 要发现的违规行为：组件直接连接后端端口、猜测尚未批准的字段，或把访问令牌写入 URL、Cookie、localStorage 或日志。
- 真实风险：开发/演示行为漂移，密钥暴露，前后端 Agent 对同一数据产生不同理解。
- 安全路径：只调用同源 `/api`；契约未冻结时保持空状态，冻结后由共享客户端类型承载。

### 真实完成状态

- 要发现的违规行为：用假资料、假统计或无效控件暗示功能已经完成。
- 真实风险：用户无法分辨脚手架和可用产品，验收结论失真。
- 安全路径：使用明确的空状态和阶段说明；业务能力只在相应实现任务通过后出现。
