# StudyPilot 任务索引

本文件记录经过确认的开发任务。创建任务前使用 `docs/governance/templates/TASK_TEMPLATE.md`，并通过 `$studypilot-task-intake` 检查是否具备写入条件。

## 状态说明

- `DRAFT`：内容不完整，禁止写入；
- `READY`：边界和验收条件完整，可以分配；
- `IN_PROGRESS`：正在实现；
- `IN_REVIEW`：等待或正在独立审查；
- `IN_ACCEPTANCE`：正在阶段验收；
- `ACCEPTED`：已通过验收，等待用户决定；
- `MERGED`：用户已确认并完成合并；
- `RETURNED`：退回原负责 Agent 修订；
- `BLOCKED`：缺少决定、权限或依赖；
- `CANCELLED`：用户取消。
