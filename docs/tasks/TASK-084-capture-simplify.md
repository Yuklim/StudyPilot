## 需求与范围

### 现状（登记前核实）

认出文献且抓到 PDF 时，`/capture` 确认页从上到下是：

1. `来自：<原页地址>`
2. **勾选框「保存这份 PDF（xxx.pdf，2.1 MB）」** + 一整段解释（勾/不勾两种文案）
3. `标题` 输入框
4. **勾选框「这页看起来是一篇文献，一并存下来」** + 类型/作者/年份/出处/DOI 的明细表
5. 「保存为资料」按钮

两个勾选框管的是**两件不同的事**，但它们是分两次长出来的，用户看不出区别：

- 「保存这份 PDF」（TASK-080）决定**存什么内容**：勾＝PDF 原件存成 FILE 资料；不勾＝改存网页正文。
- 「这页看起来是一篇文献，一并存下来」（TASK-075）决定**存不存文献元数据**（作者/年份/DOI），
  与上一条正交。TASK-075 落地时还没有抓 PDF 这回事。

两者默认都勾着，且对一篇论文来说答案几乎永远是「都要」。

### 目标

1. **认出文献且抓到 PDF 时，不再要求用户做任何勾选**：直接存 PDF 原件 + 文献信息，
   确认页只保留「这次会存下什么」的**一句陈述**、文献明细表（供核对是不是这篇）、标题框、保存按钮。
2. **认出文献但没抓到 PDF 时**（跨域/付费墙/超限/超时），同样不再要求勾选文献信息：
   存网页正文 + 文献信息，并保留既有的「为什么没拿到 PDF」提示。
3. **没认出文献的普通网页：行为一字不变**。这是最容易误伤的地方，须有用例钉住。
4. 失败处置不变：文献信息写失败时仍停在本页、如实说明、给「打开这份资料」的出口。

### 非目标 / 禁止范围

- 不改抓取逻辑、不改契约、不改扩展。
- 不改「连图片一并保存」那条既有路径。
- 不动资料详情页的「信息」Tab（文献信息事后修改的出口在那里，本任务依赖它但不改它）。
- **不写 `docs/tasks/任务索引.md`**：TASK-083 未合并且持有索引，本任务索引行并入下一个已授权任务
  的控制面提交（AGENTS.md §3/§5 与用户既定指令）。

### 主 Agent 登记的决定与取舍（用户给了方向，这几条是我定的具体形状，Review 可挑战）

- **两个勾选框都去掉，而不是只去掉一个**。用户说的是「不要让用户做太多选择」，只去掉一个
  仍然留着一个语义含糊的框。
- **被去掉的两条退路，代价明示**：
  - 「不存文献信息」→ **仍有出口**：存完之后在资料详情页右栏「信息」Tab 可以改或清空（TASK-078）。
  - 「改存网页正文而不是 PDF」→ **没有等价出口**，只能重新采集（而重新采集还是会存 PDF）。
    判断：用户在 TASK-080 定案时明说「原文页一般都是对文献的描述，没用」，此路本就是
    为极少数情形留的后门；为它保留一个每次都要看一眼的勾选框不值得。**这一条如实登记，
    若 Review 或用户不同意，改回一个「改存网页正文」的次要入口即可。**
- **文献明细表保留**：它不是选择，是**核对**——让用户一眼看出认出来的是不是这篇论文。

### 落点

- 删掉 `savePdf` 与 `saveCitation` 两个 state 及其勾选框。抓到 PDF 就存 PDF，认出文献就存文献信息。
- PDF 那块换成一句陈述（`.capture-plan`）：「这次会存下：**PDF 原件**（名字，大小）和下面这份文献信息。
  打开资料就能在 StudyPilot 里读，这一页的正文不会保存——它只是对这篇文献的描述。」
- 文献明细表**保留**，抬头改为陈述：有 PDF 时「这篇文献的信息：」，无 PDF 时「这页看起来是一篇文献，
  会一并存下来：」。它不是选择，是让用户一眼核对认出来的是不是这篇。
- **页面大标题跟着产物变**：存 PDF 时是「确认要保存的**文献**」，否则仍是「确认要保存的正文」。
  这一处是**实测截图时才发现的**——标题写着「正文」而正文下面那句写着「这一页的正文不会保存」，
  两句当场打架。单测断言的是文字内容，看不出这种整页读起来的矛盾。

### 实测（真实 Edge + 真实 arXiv 载荷）

用构建后的注入脚本在真实 `arxiv.org/abs/1706.03762` 上采到真载荷（2.11 MB PDF + PREPRINT 文献），
再投进真实 `/capture` 页：

| 情形 | 页面标题 | 勾选框 | 正文框 |
| --- | --- | --- | --- |
| 论文 + 抓到 PDF | **确认要保存的文献** | **0** | 不显示 |
| 论文 + 没抓到 PDF（`failed`） | 确认要保存的正文 | **0** | 显示，含失败原因与文献明细 |
| 普通网页（非文献） | 确认要保存的正文 | 0 | 显示，与改前一致 |
