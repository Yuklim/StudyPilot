# StudyPilot

StudyPilot 是一个面向个人学习者的资料收集与随手心得助手。目前可以在简约手帐风页面中保存网页、粘贴内容和原始文件，按主题/标签或关键词找回资料，并直接写下、回看、修改和删除自己的心得。旧学习历史及状态/归档管理仍保留在辅助入口；复习、统计和 AI 尚未开放。

如果你刚开始学习开发，可以把“脚手架”理解为房子的基础结构：它先保证门、墙和水电线路的位置正确，之后的任务才会逐步加入真正可用的房间和家具。

## 当前有什么

- Python 3.13 + FastAPI 后端，可通过 `GET /health` 确认进程正常运行；
- 本机访问安全门禁：可信 Host、来源上下文和每次启动轮换的内存令牌；未授权 `/api/v1` 请求在读取正文或操作文件/数据库前拒绝；
- React + TypeScript + Vite 简约手帐风前端应用壳：暖纸色、灰绿、圆角、书页和便签细节；共用导航、手机布局、全局错误边界与明确的未接入提示；
- Ruff、mypy、pytest、Prettier、ESLint、TypeScript、Vitest 和正式前端构建检查；
- uv 与 npm 锁文件，用来在不同机器安装同一组依赖版本。
- SQLAlchemy 数据模型和 Alembic 初始迁移：前者让 Python 操作数据库，后者按版本创建或升级表结构；目前只支持 SQLite。

网页、文件与粘贴资料页面已接入真实后端。没有示例资料冒充真实数据；未开放功能会明确提示，不放置无效操作按钮。

### 可以使用哪些页面（TASK-007 / TASK-010 / TASK-012 / TASK-014）

导航、返回和浏览器前后退可用；资料库、添加资料、资料详情/心得、分类整理和旧学习历史已接入，复习与统计等仍为明确标记的功能预留。

| 页面 | 本地路径 |
| --- | --- |
| 学习概览 | `/` |
| 资料库 | `/resources` |
| 添加网页、文件或粘贴资料 | `/resources/new` |
| 资料详情 | `/resources/:resourceId`（从资料卡片打开；不存在的编号显示受控提示） |
| 学习记录 | `/study-records` |
| 复习安排 | `/reviews` |
| 主题统计 | `/topics` |
| 分类整理（主题与标签管理） | `/classifications` |

直接访问或刷新这些地址仍能显示页面；其他地址会提示“没有找到这个页面”，并提供返回入口。统计用“— / 未接入”表示未连接数据，不是零记录。已开放的资料、分类、心得与旧学习历史按需请求同源接口；不加载外部素材，不在浏览器持久化凭据、草稿或原文。键盘用户可按 Tab 找到“跳到主要内容”；切换页面后焦点会移到新标题。

## 产品方向（2026-09-03 修订）

StudyPilot 的基础是**收集学习资料、随手记录心得、之后再次找回**。TASK-019 已将默认记录简化为心得正文：不要求填学习开始时间、时长、百分比和学习后状态；复习、详细统计和 AI 等延后迭代。详见[项目需求说明](./项目需求说明.md)第 5/8 节。

TASK-018 已修正需求与顺序；TASK-019 按该方向接入轻量心得页面，复用已合并 TASK-017 的后端。已有学习历史不删除、不迁移为心得；基础功能优先，扩展不因为已有菜单或模型就提前开发。

## 需要先安装的软件

| 软件 | 本项目版本 | 用途 |
| --- | --- | --- |
| Git | 当前受支持版本 | 下载代码并查看修改历史 |
| uv | 当前受支持版本 | 安装 Python 3.13、后端依赖并运行后端命令 |
| Node.js | 24 LTS | 运行前端开发工具 |
| npm | 11.x（随 Node.js 24 提供） | 按锁文件安装前端依赖 |

`LTS` 是 “Long-Term Support（长期维护）” 的缩写，表示该 Node.js 主版本会获得较长时间的错误修复和安全更新。仓库中的 `.python-version` 与 `.node-version` 分别固定 Python 3.13 和 Node.js 24；后端的 `uv.lock` 与前端的 `package-lock.json` 进一步固定依赖的精确版本。

可以先在终端检查工具是否存在：

```bash
git --version
uv --version
node --version
npm --version
```

如果某条命令显示 “command not found（找不到命令）”，请先安装对应软件，再继续下面的步骤。

## 第一次安装

打开终端，进入本仓库根目录。然后安装后端依赖：

```bash
cd backend
uv sync --locked
cd ..
```

`uv sync --locked` 会按锁文件创建本项目自己的 `.venv` 虚拟环境；它不会把依赖混入系统 Python。若电脑上还没有 Python 3.13，uv 会按配置安装合适的 Python 运行时。

再安装前端依赖：

```bash
cd frontend
npm ci
cd ..
```

`npm ci` 表示按照 `package-lock.json` 进行一次干净、可复现的安装。生成的 `.venv/` 和 `node_modules/` 只存在于本机，已经被 Git 忽略。

## 启动顺序

开发时需要两个终端窗口：一个运行后端，一个运行前端。

### 1. 建库并启动后端

在第一个终端中，从仓库根目录运行：

```bash
cd backend
uv run alembic upgrade head
uv run uvicorn studypilot.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

首次使用资料功能必须显式建库；已有真实数据升级前，先停止服务并备份数据库。请让迁移与服务使用同一终端、同一目录和数据库配置，详见“数据库运行配置”。应用启动和健康检查不会自动建表。

看到 Uvicorn 的启动信息后，可在浏览器打开 <http://127.0.0.1:8000/health>。正确响应只有：

```json
{"status":"ok","service":"StudyPilot"}
```

`127.0.0.1` 表示只允许这台电脑自己访问。不要把启动地址改成 `0.0.0.0`；当前项目没有公开部署所需的身份认证和其他安全保护。

### 2. 启动前端

保持第一个终端运行，再打开第二个终端，从仓库根目录运行：

```bash
cd frontend
npm run dev
```

然后在浏览器打开 <http://127.0.0.1:5173>。页面应明确显示：

> 网页与粘贴资料已开放

前端开发服务器提供同源 `/api` 代理。前端业务代码只能访问 `/api`，不能把后端端口写死在组件中。资料库和详情需要后端运行且已建库；只开前端仍可浏览概览和填写表单，但不能读取或保存资料，会显示错误而不是假数据。

### 3. 保存和阅读第一份资料（TASK-010）

1. 点击“添加资料”，选择网页链接或粘贴内容，填写标题与必填来源；来源名称和保存原因可不填。
2. 点击“保存到资料库”，成功后进入详情。网页只保存地址，点击外链才打开原网站；粘贴原文按纯文本展示，HTML/Markdown 不会被执行或解析。
3. 回到资料库，输入搜索词或选择类型、状态、排序，再点击“搜索 / 应用筛选”。支持卡片/列表切换和每页 20 条分页；搜索仅覆盖标题、来源名称和保存原因，不搜原文。默认隐藏已归档，选择“已归档”可以单独查看。

草稿、选择的文件与筛选只在当前页面内存中；离开或刷新会清空。保存中不会重复提交；网络或响应错误可能无法确认是否已保存，请先查看资料库，避免重复添加。不会自动重试保存。资料删除页面尚未开放，新增资料初始学习状态为“未开始 · 0%”，不是虚构的学习记录。

### 随手写心得（TASK-017 后端 / TASK-019 页面 / TASK-027 独立心得入口）

在资料详情的“随手记心得”里写一句理解或疑问，点击“保存心得”即可。无需填写学习开始时间、时长、进度或学习后状态；系统显示实际保存/更新时间，不推断学习投入，也不改变资料进度或追加虚构学习活动。

下方“留下的心得”支持分页回看、编辑和删除。正文按纯文本展示；每条最多 50,000 个字符，保留内部换行。编辑会先读取当前内容；删除需核对具体内容并确认，**没有回收站**，不会连带删除资料、其他心得或旧历史。心得暂不参与资料关键词搜索，也不出现在全局旧学习历史里。

草稿只在本页内存中，翻页或修改标签不会清空；切换另一条编辑/删除操作前会提示放弃未保存草稿。刷新、离开或关闭页面前请先保存。资料重读期间暂不允许写入，草稿仍在；不承诺跨刷新恢复。

冲突或操作结果不确定时，保留草稿并停止再次写入。点击“保留草稿，读取最新心得”，核对最新内容与自己的草稿，确认后才能再次保存/删除；读取失败不会解锁。若请求已在后端成功但响应丢失，查看实际心得避免重复保存；不会自动重试，也不承诺网络故障下恰好一次。心得已经不存在时可以明确选择将草稿作为新心得继续编辑，但不会自动创建。

侧栏主入口「我的心得」（TASK-027）用于不先收藏资料也随手记下的独立心得：不必进入某份资料即可写下一句理解或疑问，并可回看、修改和删除。独立心得不绑定资料；绑定在资料详情的心得仍在那里记录与回看，两类心得互不混列。删除某份资料只级联删除它名下的心得，独立心得不受影响。独立心得的保存/编辑/删除同样遵循上面的版本冲突核对与“结果不确定不重复写”规则。

### 旧学习历史与可选管理（TASK-015 / TASK-016，TASK-019 收起入口）

在详情下方点击“查看旧学习历史”可回看旧记录。需要继续使用原来的状态/归档功能时，再展开“更多：状态与归档管理”；它不是记录心得的前置步骤。该旧表单仍按既有契约填写开始时间、时长、状态/进度及总结，保存后更新进度并保留变化历史，不替用户猜测学习数据。

归档前需勾选影响确认；原件、进度和历史保留，资料只从默认资料库隐藏，可筛选“已归档”再打开恢复。恢复只回归档前的状态。未开始需要手动填写进度 0，不自动清零。

冲突、断网或无法确认结果时会保留本页草稿并暂时禁止保存。点击“保留草稿，读取最新进度”，检查刷新后的历史，再勾选重新确认；不会自动重发。重新读取失败时仍保持锁定。收起表单、离开、刷新或重新加载资料会丢弃草稿，但不会撤销已发出的请求。

侧栏“学习记录”查看全局历史，详情手帐查看单份资料历史；可按开始时间范围、排序和分页查看，结束时间边界不包含。记录中的总结与疑问按纯文本显示；没有记录会明确提示，不用示例充数。全局每条记录可打开其对应资料；高级主题/资料筛选本次未加入。

已实现三个接口：单资料学习记录的新增/分页读取，以及全局学习记录分页读取。每次记录可包含开始时间、时长、前后状态/进度、总结和疑问；保存采用事务（进度和历史要么一起成功，要么一起撤回），不自动重试不确定的写入。

版本与前值校验防止旧页面覆盖新进度。100% 不自动标记完成；回到未读必须明确提交 0%；归档保留进度与时间，恢复只回原状态。首次开始时间保留，重新开始会清空当前完成时间，但历史不被覆盖。仅补总结而不改变当前进度时，不伪造版本或更新时间变化。历史不提供修改或删除入口。

复习相关状态要求已有正确的计划；学习接口不会代替复习模块创建、暂停或完成计划。复习和概览统计仍待后续任务；心得使用独立的笔记接口，不与旧学习记录重复填报或混存。

接口复用本机令牌保护，仅限本地单进程使用。SQLite 竞争写入若锁定会返回受控失败并回滚，不会自动重放；应先重新读取最新进度/历史，再由用户明确决定是否再次提交。

### 个人笔记后端（TASK-017，TASK-019 已接入心得页面）

一份资料可保存多条个人笔记，支持列表、详情、新增、修改和删除五个接口。正文去首尾空白后为 1～50000 字符，保留内部换行，仅作为文本存储，不执行或解析，也不生成 AI 内容。笔记与原件、保存原因和学习总结独立，不进入资料统一搜索。

修改使用读取到的版本，防止旧内容覆盖新内容；文本未变时不更新版本与时间。删除要求当前版本，只删除指定资料下的指定笔记，不能通过更换资料 ID 读取或修改其他笔记。笔记删除是直接删除，没有回收站；后续页面需明确提示用户。

所有写入在数据库事务成功后才返回成功，失败会回滚，不自动重试。SQLite 写入竞争可能返回受控失败；保存或删除结果不确定时应先重新读取，而不是重复提交。归档资料仍可访问笔记；未就绪或损坏的 FILE 资料不能通过笔记接口绕过可见性规则。页面使用方式见上方“随手写心得”。

### 上传与下载文件（TASK-014）

在“添加资料”选择“上传文件”，填写标题并选择一个 PDF、Word、Markdown 或 TXT 原件；最大 25 MiB（约 26 MB）。可以移除重选，也可选择已有主题/标签。页面提前检查空文件、大小、扩展名，真实格式由后端检查；浏览器的文件类型提示不能代替后端校验。

点击“保存到资料库”后等待上传与保存完成，不显示虚假的百分比。失败会保留当前页文件和输入；如果提示结果未确认，请先到资料库查看，不要连续重传。成功后进入详情，也可在资料库按“文件”筛选后打开。

详情中的“下载原件”会向本机后端请求经过完整性校验的文件，只交给浏览器下载，不在页面内预览或执行。下载失败会显示固定原因；再次点击才重试。页面提示“已交给浏览器”不等于已写入你的下载目录，请查看浏览器下载列表。内容尚未解析，也未扫描病毒，请只打开可信原件。

### 整理主题与标签（TASK-012）

1. 打开“分类整理”，切换主题或标签，可新建、搜索、排序、分页、修改；主题还可填写说明。未使用分类可在明确确认后删除，使用中的分类会提示影响数量并拒绝，不连带删除资料。标签没有颜色或描述字段。
2. 添加资料时展开“选择主题与标签（选填）”，选一个主要主题、最多 20 个已有标签；也可以不选。选择器按需分页，搜索/翻页/收起不清空已选项，移除已选项不会删除分类本身。所有分类与资料在原有单次保存中一起提交。
3. 资料库展开“按主题与标签筛选”，可选指定主题或“仅未分配主题”、多个标签。多个标签要求全部具有；和关键词、来源、状态同时满足，点击应用生效，重置回第一页。分类选择器最多同时选择 20 个标签。
4. 资料详情显示主题名称，点击“管理这份资料的标签”可逐个添加或解除；每次只改一条关联，成功后从服务重新读取，不覆盖整组标签。主要主题后补/重分配仍待资料修改接口，不能在本页更改。

版本保护表示“只修改自己刚看过的版本”。旧页面遇到冲突会保留输入并拒绝覆盖，需明确“放弃草稿，载入最新版本”后重新确认；网络失败不会自动重试。草稿在离开、刷新或切换主题/标签页时丢弃；离开页面不会撤销已发送请求。资料接口只返回主题 ID，所以页面按每次读取的不同主题补查名称；补查失败只提示名称暂不可读，不隐藏资料。

### 本机访问保护与共享客户端（TASK-008）

本地令牌是每次后端启动重新生成的临时通行证，不是账号密码，也不是 AI 的 API Key。可信页面通过 `GET /api/v1/local-session` 初始化；后端严格检查 Host 和浏览器自动提供的来源上下文。直接把该地址输入地址栏、普通无令牌请求或外部网页请求都会返回 403，这不是服务故障。`/health` 仍只返回固定健康状态。

默认只信任后端 `127.0.0.1:8000` 与界面 `http://127.0.0.1:5173`。进程配置 `STUDYPILOT_API_PORT` / `STUDYPILOT_UI_PORT` 可以显式调整端口，但不会替你改变监听地址；必须同时调整 uvicorn 端口、Vite 端口及固定代理目标，重启后精确一致。不要改成 `localhost`、IPv6、局域网地址或通配来源；没有自动信任外部 Host 的行为。`.env.example` 只供参考，变量仍须显式 export，不会自动加载。

只运行 **一个后端 Worker（服务进程）**；令牌属于当前进程，暂不支持多个进程负载均衡。后端重启后旧令牌立即失效；页面刷新会清空内存，下次请求重新初始化。不保存令牌到 Cookie、localStorage、sessionStorage、IndexedDB、URL 或日志，也不要手工粘贴到代码/截图/测试输出中。启动示例关闭请求访问日志，避免未来查询参数被记录。

后续功能从 `frontend/src/api/client.ts` 导入 `api`：`await api.connect()` 按需连接，`api.request('/api/v1/…', { method, body })` 用于 JSON 请求。并发初始化会合并为一次请求；成功返回完整 `{data, ...}` 响应（保留分页字段），具体功能再校验自己的数据类型；204 返回 undefined。调用方不能覆盖令牌、来源、重定向或 Cookie 策略。对失效令牌会清除缓存并报告 `ApiError`，**不自动重放请求**；用户明确重试或再次调用时才重新连接。错误只包含受控说明、状态、代码和安全请求编号，不复制服务端原文。文件使用固定入口的 `api.uploadResource(FormData)` / `api.downloadOriginal(fileId)`，不暴露凭据或原始 Response；下载流有界读取并验证附件、规范类型与大小，临时对象 URL 在交给浏览器后或离页时释放。删除确认仍未接入，不使用 JSON 入口伪装已完成。

TASK-012 仅为分类 DELETE 增加 `ifMatchVersion: 正整数`，内部生成强 `If-Match` 头；只接受主题/标签单项路径、DELETE、无正文，不提供任意请求头入口。分类错误额外保留已校验的 `current_version` 或 `resource_count` 数值，其他服务端 details/message 丢弃，不暴露凭据。

开发代理先校验界面的精确 Host（Vite 默认允许的 localhost/IP 别名也不能绕过），再固定后端 Host；同时关闭 Vite 默认 CORS 处理，使 API 预检也到达后端白名单校验。合法预检返回 204，非法预检返回 403；不允许通配或凭据 Cookie。配置依据：[Vite Host、代理与 CORS 选项](https://vite.dev/config/server-options.html#server-cors)。CORS（浏览器跨来源访问限制）只是附加防线，不替代令牌与来源校验。

**安全连接不等于公网认证或完整业务完成。**未实现的业务路径仍不可用；没有自动迁移数据库。禁止直接公网部署、开放多个账号或宣称全部业务闭环已通过。

### 资料后端（TASK-009）

已完成三个接口：`POST /api/v1/resources` 保存 JSON 网页/粘贴资料；`GET /api/v1/resources` 分页搜索/筛选/排序；`GET /api/v1/resources/{id}` 读取详情。TASK-010 页面通过共享客户端接入，无需手动复制临时令牌。

TASK-020 增加既定 `PATCH /api/v1/resources/{id}`，TASK-021 接入详情页的“编辑资料”：可修改标题、来源名称、保存原因 / 简介、主要主题，以及 WEB 的链接或 PASTE 的原文。编辑区默认收起，原始内容另行展开；原文覆盖没有修订历史，文件原件和资料类型不能更换。不改心得、学习进度、旧历史或标签，也不清空正在填写的心得草稿。

只提交改动字段；来源名称、简介、主题可清空，标题去首尾空白，粘贴原文保留空白和换行。页面自动携带读取时的 `expected_version`（用于防止旧页面覆盖新修改的版本号），未修改时不发送保存请求。遇到版本冲突或保存回执丢失，会保留草稿并暂停再次保存；先点“保留草稿，读取最新资料”，核对服务器上实际保存的内容，再明确确认是否重提。不会自动重试；重提也不会覆盖本页没改过的字段。草稿仅在当前页面内存中，离开或刷新会丢失，取消编辑需确认放弃；不提供自动保存或历史版本恢复。

用户已确认分阶段交付：当前可用范围见[契约第 1.3 节](docs/contracts/API与数据契约基线.md#13-task-009-阶段性交付与当前可用范围-用户确认架构)及 OpenAPI 的 `x-delivery-profile`。完整 OpenAPI 保留最终 MVP 目标，不表示所有操作现在都可用。TASK-013 已实现文件 multipart 后端，解除此前的临时媒体类型限制；JSON 仍只接受 WEB/PASTE。清单与实现一起接受测试、独立审查、验收和用户合并，不能据完整目标自动开放未交付操作。

使用这些接口前，须按照下文“数据库运行配置”显式运行 `uv run alembic upgrade head`，在同一后端工作目录使用同一数据库配置；服务启动与 `/health` 不自动建表。资料和初始“未读、0%”进度以及标签关联一起保存，失败一起撤销；应用重启不丢数据。未建表或数据库故障返回受控错误及请求编号，不暴露 SQL、路径或原文。

网页只保存链接，不抓取网站；拒绝非 http/https、带账号密码或片段的地址。粘贴原文原样保存，列表不返回全文或原始网址，详情才返回。搜索仅覆盖标题、来源名称、保存原因，不搜粘贴正文。默认列表排除归档，可显式筛选；多个标签需全部符合，排序相同值按 ID 保持稳定。

资料创建可引用已有主题/标签；TASK-011 提供分类接口，TASK-012 页面已接入选择与筛选，省略主题/标签也可保存。资料修改由 TASK-020 后端提供，主要主题可重分配或清空；资料删除与编辑页面尚未开放，已有学习/心得能力保留。Unicode 搜索为保持跨数据库语义一致，在已筛选的元数据上执行内存匹配；不加载粘贴正文，适用于当前个人/低流量规模，资料规模显著增长后再按测量优化。每次显式业务请求使用独立数据库会话，结束关闭，不共享可变状态。

### 原始文件后端（TASK-013）

- 支持 PDF、Word（DOC/DOCX）、Markdown 和 UTF-8 TXT，单文件 1～25 MiB；格式与内容不符、空文件、超限和路径伪装会拒绝。默认未知/通用二进制 MIME 由内容识别，明确矛盾的声明不接受。这是格式识别，不是病毒扫描或正文解析。
- 已授权的同源表单向 `POST /api/v1/resources` 提交 `source_type=FILE`、`title`、一个 `file`；可选公共分类/说明字段遵守契约，`tag_ids` 使用重复字段。TASK-014 页面和共享客户端已接入，请勿把令牌复制进网址、日志或持久化存储。
- 数据先存入随机暂存文件，数据库登记 PENDING 后原子提升，第二次事务复核并提交 READY 才成功。按 `/api/v1/files/{file_id}/download` 下载，逐次核对大小和 SHA-256（内容校验值），只作为附件返回。
- `STUDYPILOT_FILES_ROOT` 默认 `./var/files`，相对后端启动目录，内部 staging/objects/trash 同卷且不允许符号链接。用绝对路径可避免切换启动目录误读另一位置；数据库与整个文件目录应停服后一起备份，不能只备份 SQLite。不要把其他文件手工放进受控目录或修改随机原件。
- 启动及每 60 秒检查已存在的库与原件，不创建库/表或执行迁移。10 分钟未完成的 PENDING 标记失败；损坏/缺失 READY 禁止下载；仍有数据库记录的 trash 可恢复。无记录、无活动上传且至少 24 小时的随机暂存/最终/trash 孤儿才回收，不删除用户资料记录。
- 只支持已确认的本机单进程运行，不要加 `--workers` 或同时启动多个后端共享同一目录。复杂格式校验在限时子进程完成（6 秒墙钟、4 秒 CPU；Linux 额外内存上限，macOS 无此系统内存限额），DOCX 解压校验预算 128 MiB；极端复杂/高压缩文件可能被保守拒绝。当前运行/验证平台为 macOS，Windows 未适配。
- 自动恢复不是备份。目录不可用或对账延迟只记录固定错误代码，不记录原件、路径或数据库参数；修复目录权限后下一周期重试。失败资料暂不在普通列表展示，需重新添加；不自动重放上传请求。

### 分类后端（TASK-011；TASK-012 已接入页面）

- 主题和标签分别支持创建、分页/名称搜索/排序、读取、修改，以及删除未使用项。名称规范化后唯一，避免全角/半角、大小写或空白差异造成重复分类；Topic 可保存描述，Tag 没有颜色或描述字段。
- 修改携带读取时的 `expected_version`；删除携带强版本头 `If-Match: "1"`。旧版本返回 `409 VERSION_CONFLICT`，没有可用版本前置条件则拒绝；不允许旧页面静默覆盖新修改。无实际变化不增加版本。
- 分类还被资料使用时返回 `409 TAXONOMY_IN_USE` 和安全计数，不连带删除资料。主要主题由资料模块分配；本任务不提供主题批量转移，也不直接清空资料的主题。
- 资料标签支持 `PUT /api/v1/resources/{resource_id}/tags/{tag_id}` 添加、`DELETE` 解除。两者“幂等”，即重复执行不会多加标签或误删其他关联；只修改这一条关联，不改变正文、主要主题、资料版本或学习进度。

本次使用已有数据库结构，无新迁移。所有写入确认提交后才返回成功；遇到 SQLite 写锁竞争可能返回受控失败，不自动重放写操作。只有主题/标签分类删除可用，**不代表资料删除已实现**。分类页面经共享客户端的受控版本选项完成删除，不要手工复制临时令牌或绕过保护。

### 浏览器扩展工程骨架（TASK-037）

`extension/` 是仓库的第三个顶层代码目录，放浏览器扩展。它是独立的 npm 工程，不与 `frontend/` 共用依赖，**只支持 Chrome 与 Edge**（同属 Chromium），不支持 Firefox 与 Safari。

用法：在想保存的网页上点扩展图标 →「保存这一页的正文」→ **若这一页的正文里有图片，会再问你一次「连图片一并保存」还是「只保存正文」**；选前者时浏览器会弹出授权框，允许后扩展才能去下载这些图片 → 浏览器打开 StudyPilot 的确认页，核对标题与正文后点「保存为资料」，资料与正文快照一起保存，图片在正文保存成功之后逐张下载。**不点确认就什么都不会保存。** 不授权、或某张图下载失败时，那些图片仍指向原网站，确认页会如实告诉你有几张没保存、分别是什么原因。**一处例外**：一次采集最多处理 60 张图片，超出的在提取阶段就被截断，确认页不会提到它们。

```bash
cd extension
npm ci
npm run build
```

构建产物在 `extension/dist/`。Chrome：打开 `chrome://extensions` → 右上角「开发者模式」→「加载已解压的扩展程序」→ 选该目录。Edge：打开 `edge://extensions` → 左下角「开发人员模式」→「加载解压缩的扩展」→ 选该目录。改代码后重新 `npm run build`，再在扩展页点一次刷新。**加载步骤已在 Edge 实机验证；Chrome 尚未实测**（同内核，manifest 无分支专有字段）。

manifest 安装时只申请 `activeTab`、`scripting`、`storage`，外加一条**只匹配 `http://127.0.0.1:5173/*`（本机 UI 源）** 的内容脚本；**不申请永久的 `host_permissions`**。`activeTab` 只在你点击图标之后授予当前那一个标签页，用完即失效——扩展只能读到你主动指定的那一页，而且只能读到它**已经显示出来**的内容；它不读 cookie、不接触任何网站的登录态。**保存图片需要额外的站点权限，且是可选的**：manifest 写的是 `optional_host_permissions: ["<all_urls>"]`，**安装时不授予**；只有当这一页的正文里有图片、且你点了「连图片一并保存」，浏览器才会弹出「读取网站数据」的授权框。你可以拒绝，也可以事后在扩展设置页撤销——两种情况下正文照常保存，图片继续指向原网站。取图由 `background` service worker 完成，那是扩展**唯一**会主动发网络请求的地方，且取图时不带任何站点凭证（`credentials: 'omit'`），所以需要登录才能看到的图片取不到。**一处例外要说明**：提取前会对页面做两处图片属性归一化，页面内容不会被改动，但极少数情况下可能出现一次图片跳变。**另外**：你点了采集却没打开确认页时，那篇正文会暂存在扩展的本地存储里，直到下次采集覆盖它或下次打开确认页时清除。`extension/src/manifest.test.ts` 以白名单断言锁住 manifest 的顶层键集合与权限清单，任何新增都会让测试失败，以保证这类改动必须经过任务与独立审查；另有一条断言钉住「站点权限必须留在 optional 里」，把 `<all_urls>` 挪进安装时权限会立刻变红。扩展不直接调用后端 API，内容一律经本机 UI 页面转交，边界与理由见 `extension/AGENTS.md` 与契约文档第 14 节。

### 共用测试工具

测试夹具（fixture）是可重复使用的“测试准备和收尾”。新后端测试直接声明需要的参数，不要从别的 `test_*.py` 文件导入辅助函数：

| 入口 | 提供什么 |
| --- | --- |
| `runtime`（自动启用） | 每测试独立临时工作目录、SQLite URL、`runtime.files` 文件目录；设置并清理配置缓存 |
| `database` | 使用已提交 Alembic 迁移创建的临时 SQLite Engine，退出时释放连接池 |

### 数据库运行配置

应用导入和启动仍然不连接、创建或迁移数据库。`.env.example` 只是配置示例，程序**不会自动加载 `.env`**；需要时在当前终端用 `export STUDYPILOT_DATABASE_URL=...` 显式设置。

只浏览未接入的概览等页面无需建库；使用资料库和保存功能必须先建库。在仓库根目录执行：

```bash
cd backend
uv sync --locked
uv run alembic upgrade head
uv run alembic current
uv run alembic check
```

`upgrade head` 将数据库升级到最新版本；重复执行不会清空已有数据。`current` 显示版本，`check` 比较模型与数据库是否存在待迁移的结构差异，但不能代替迁移审查。初始版本是 `0001_initial`，包括 11 张业务表和 1 张版本表。

默认 URL 为 `sqlite:///./var/studypilot.db`，相对路径基于**命令运行目录**：按上述步骤得到 `backend/var/studypilot.db`。切换目录时请使用绝对 URL（例如 `sqlite:////绝对路径/studypilot.db`），避免误建另一个库。只有显式调用连接工厂或迁移命令才创建所需目录；连接工厂不自行建表。

每次对已有数据迁移前，先停止应用和所有数据库写入进程，备份数据库及关联文件，并确认目标路径。初始迁移的降级只允许业务表全空的开发库；只要任一业务表有数据，就在删除任何表之前拒绝执行。不要对真实资料库运行降级或依赖它作为备份替代品。

数据库访问统一通过 `infrastructure.database` 的连接工厂、会话工厂和 `session_scope` 事务入口。事务即“一组写入全部成功才保存，失败则全部撤销”；每次使用独立会话，不共享可变 Session。每个 SQLite 连接开启外键、设置 5 秒锁等待；测试只在临时目录执行迁移，不触碰默认库。

字段范围、枚举、唯一性和外键由数据库约束；Python 对象映射（ORM）负责时区转换、名称规范化、版本冲突以及普通对象写入保护。时间点必须带时区，按 UTC 保存和读取，日历日期不转换。正常无变化更新不会增加版本。ORM 钩子和版本保护**不覆盖直接 SQL 或批量更新**；后续应用服务须走普通 ORM 写入，不得绕过这些保护。插入关联对象时先保存并 `flush` 父对象；本阶段只有外键，未引入自动关联保存。

初始模型位于共享基础设施，表的 `info.owner` 保留 resources/taxonomy/learning/notes/reviews 的原有职责。历史学习/复习记录拒绝普通 ORM 修改或直接删除；资料删除可通过数据库级联删除关联记录，但不会删除主题、标签或删除确认记录。确认表只存令牌摘要，不存原始令牌。**文件状态流转、完整 URL 校验、跨表状态一致性、删除确认和保留期清理仍由后续业务任务实现**，数据库基础不表示这些操作已获准开放。当前未安装或验证 PostgreSQL 驱动，不承诺只改 URL 就能切换。

枚举采用显式表约束，使 Alembic 能可靠比较；迁移版本不导入可变模型。连接与时间处理参考 [SQLAlchemy SQLite 说明](https://docs.sqlalchemy.org/en/20/dialects/sqlite.html) 和 [UTC 时间存储示例](https://docs.sqlalchemy.org/en/20/core/custom_types.html#store-timezone-aware-timestamps-as-timezone-naive-utc)。

未来的数据库、上传原件和回收站等运行数据统一放在 `var/` 或由配置指定的本地目录。以下内容都不会进入 Git：

- `.env` 和其他本地环境配置；
- `.venv/`、`node_modules/` 和构建产物；
- SQLite 文件、上传文件、trash、日志、缓存和覆盖率报告。

不要把 API Key、Token、Cookie、真实学习资料或私人笔记写入源码、测试或示例配置。

## 常见问题

### 为什么打开 `http://127.0.0.1:8000/` 是 404？

当前后端提供 `/health`、受保护的本机连接与已交付业务接口，不提供根页面。404 的意思是“这个地址目前没有对应页面”，不是后端没有启动；界面在前端的 5173 端口。

### 为什么访问 `/api/v1/...` 返回 403？

403 的意思是“服务器理解请求，但拒绝执行”。本机访问协议会在读取正文或产生副作用前检查 Host、令牌与来源；直接访问地址栏通常没有必要的上下文/令牌。请由可信本机页面的共享客户端连接，不要通过关闭安全检查来调试。

### 为什么资料库为空，其他页面也没有学习数据？

全新数据库没有资料，可从“添加资料”保存第一份网页或粘贴内容。若显示连接/数据库错误，请按启动顺序检查后端和迁移；空库、搜索无结果与服务失败会分别提示。概览统计、复习和正文解析尚未开放，不会用假数据填充。

### 端口已经被占用怎么办？

先确认是否已经在另一个终端启动过同一服务，并在那个终端按 `Control + C`。项目使用固定的本机地址和端口来减少前后端配置差异，不建议初学阶段随意更改。

### 安装后依然使用了错误的 Python 或 Node.js 版本怎么办？

运行 `uv run python --version` 应看到 Python 3.13.x；运行 `node --version` 应看到 v24.x。若 Node.js 不是 v24，请使用你电脑上的 Node 版本管理工具切换到仓库 `.node-version` 指定的版本后，重新运行 `npm ci`。

### `npm ci` 提示 npm 缓存没有权限怎么办？

如果错误中包含 `EACCES` 或 `permission denied`，表示 npm 以前留下的用户缓存权限异常，并不是 StudyPilot 代码损坏。不要使用 `sudo npm ci`。可以在 `frontend/` 或 `extension/` 中改用仓库内、已被 Git 忽略的临时缓存：

```bash
npm ci --cache ../.npm-cache
```

正常机器仍然直接使用 `npm ci`；这个替代命令只改变下载缓存位置，不改变 `package-lock.json` 中的依赖版本。`extension/` 与 `frontend/` 是各自独立的 npm 工程，缓存目录可以共用，`node_modules` 不共用。

### 可以直接部署到公网展示吗？

不可以。当前应用是无登录的本地单用户脚手架，本地访问边界不能替代公网身份认证。未来若需要在线演示，必须先建立独立的部署与安全任务。
